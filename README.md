# Keystanza

**Learn unfamiliar code by writing it yourself.**

Keystanza is a quiet code-copying practice tool for developers. Paste code you want to learn, then type it back while the interface marks correct and incorrect characters in real time.

The goal is familiarity, not speed. Repetition helps syntax, APIs, and framework patterns become easier to recognize and recall.

## Why Keystanza

Reading code is useful, but writing it engages a different kind of attention. Keystanza gives you a focused place to slow down and practice the exact code that matters to you.

- Practice with your own source code
- Build familiarity through deliberate repetition
- Receive immediate, character-level feedback
- Stay focused without scores, rankings, or pressure
- Keep your draft and preferences in your own browser

## How It Works

1. Open **Custom Code**.
2. Paste the code you want to study.
3. Choose your preferred code font and font size.
4. Select **Practice This Code**.
5. Type directly in the displayed code area.
6. Use **Restart** whenever you want to repeat the same passage.

Character matching is case-sensitive.

## A Quiet Practice Experience

Keystanza intentionally does not include WPM, accuracy percentages, timers, error totals, completion celebrations, or competitive rankings. It is designed to feel more like copying a poem by hand: calm, attentive, and repeatable.

## Privacy

Keystanza does not require an account. Your code, theme, and code appearance preferences are stored locally in your browser and are not uploaded to a cloud database.
